# Traps

1. **Old Explorer copies are invisible to the journal.** Resume skips only rows this program marked done. A folder full of `IMG_*.HEIC` from an earlier hand copy will be copied again.

2. **Never overwrite an existing file.** Same name and same size can be treated as already copied. Same name and a different size gets a new file beside the old one (`IMG_0140_2.JPG`). Steve, 2026-10-12: a partial folder copy once overwrote same names that did not match. A screen to pick which copy to keep is later. The default stays "new file beside the old one." Dry-run and match before the first real copy into `E:\iPhone14_8-27-2026`.

3. **Optimize iPhone Storage.** Originals that live only in iCloud are not on the phone. The copy will look finished and still be missing full-size files.

4. **Apple Devices must have been opened once after boot** or the phone looks absent. The Store app's USB service stays off until then.

5. **The tool folder and the photo folder are different drives.** The window finds the phone helper beside itself. The destination folder is whatever you pick. Unplugging the drive that holds the tool does not change the photo folder, and the other way around.
