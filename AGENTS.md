## Agent inbox (J:\slyOS\inbox)
J:\slyOS\inbox holds short reports from finished agent jobs (what was done, what was found, follow-ups). When you finish a job, write one there named YYYY-MM-DD_HHMM_<project>_<topic>.md. When Steve asks about past work or wants to find something, read those reports first (newest first) to help him locate it.
